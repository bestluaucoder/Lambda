# Lambda
Lambda is an open source CSGO hvh cheat.

## Build
Use x86 Release configuration in Visual Studio. There are no external dependencies except [DirectX SDK](https://www.microsoft.com/en-us/download/details.aspx?id=6812).

## Contribution
If you want to add a new feature or fix, please open a pull request and describe what has been changed.
